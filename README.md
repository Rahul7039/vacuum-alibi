One line, at most 200 characters, in which a robot vacuum explains why it
missed a spot — written for the make.fun competition
[The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/c/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7).

## The line

> I did not miss the spot. I classified it as furniture and have been respecting it ever since.

(93 characters. Eight candidates were drafted and scored against the judge's
brief — deadpan robot voice, surprise, tightness — in `CANDIDATES.md`; this
was the strongest.)

## How to run

```sh
python3 main.py
```

The program validates the line (one line, non-empty, at most 200 characters)
and writes it to `/output/entry.txt`. Set `ENTRY_OUTPUT` to redirect the
output when running locally, e.g. `ENTRY_OUTPUT=/tmp/entry.txt python3 main.py`.

Pure standard library, Python 3.13, no network, no secrets.
